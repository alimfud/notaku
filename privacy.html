Kebijakan Privasi NotaKu

Terakhir diperbarui: 6 Oktober 2026

NotaKu adalah aplikasi pencatatan nota dan usaha yang membantu pengguna mengelola produk, pelanggan, transaksi, pembayaran, dan laporan. Kebijakan ini menjelaskan bagaimana data diproses ketika Anda menggunakan NotaKu.

1. Data yang disimpan

Data usaha yang Anda masukkan dapat meliputi nama toko, produk, pelanggan, nomor telepon, alamat, nota, pembayaran, pengeluaran, pengaturan toko, logo, dan data QRIS. NotaKu tidak meminta kata sandi atau data kartu pembayaran.

2. Penyimpanan lokal

Secara default, data NotaKu disimpan di penyimpanan lokal browser atau perangkat Anda. Data tersebut tidak dikirim ke server NotaKu. Menghapus data browser, menghapus aplikasi, atau mengganti perangkat dapat menghapus data lokal jika Anda belum membuat cadangan.

3. Backup Google Drive

Fitur backup Google Drive bersifat pilihan. Jika Anda mengaktifkannya, NotaKu menggunakan akun Google yang Anda pilih untuk membuat dan mengelola file backup NotaKu di Google Drive Anda. Akses yang diminta menggunakan izin terbatas drive.file, sehingga aplikasi hanya dapat mengelola file yang dibuat atau digunakan oleh NotaKu.

File backup dapat berisi seluruh data NotaKu. File tersebut berada di akun Google Anda dan tunduk pada kebijakan privasi Google. Anda dapat memutuskan akun Google dari NotaKu atau menghapus file backup kapan saja.

Jika sesi Google diaktifkan, alamat email, identitas akun Google, dan token izin akses disimpan terenkripsi dalam Cloudflare KV untuk memperpanjang akses tanpa login berulang. Cookie sesi aman menghubungkan browser dengan sesi tersebut. Token pembaruan tidak disimpan dalam data backup atau penyimpanan browser. Data usaha tetap dikirim langsung antara browser dan Google Drive.

4. Penggunaan data

Data digunakan hanya untuk menyediakan fungsi pencatatan, pencarian, perhitungan, pencetakan, laporan, pemulihan, backup, dan sinkronisasi yang Anda minta. NotaKu tidak menjual data pribadi, tidak menggunakan data transaksi untuk iklan, dan tidak membagikan data pelanggan kepada pihak lain melalui server NotaKu.

5. Berbagi dengan layanan pihak ketiga

Jika Anda mengaktifkan backup, komunikasi dengan Google Drive mengikuti izin dan kebijakan Google. Jika Anda menggunakan fitur berbagi atau pencetakan pada perangkat, data hanya dikirim ke aplikasi atau perangkat tujuan yang Anda pilih.

6. Keamanan dan tanggung jawab pengguna

NotaKu berusaha menggunakan penyimpanan dan koneksi yang sesuai untuk fitur yang tersedia. Anda bertanggung jawab menjaga keamanan perangkat, akun Google, serta file backup. Jangan membagikan file backup kepada orang yang tidak berwenang karena isinya dapat memuat seluruh data usaha.

7. Penghapusan data

Anda dapat menghapus data lokal melalui pengaturan perangkat atau browser, menghapus file backup dari Google Drive, dan memutuskan akses Google Drive dari pengaturan NotaKu. Karena data utama disimpan lokal, NotaKu tidak memiliki salinan server yang dapat dihapus atas nama Anda.

Memutuskan akun menghapus sesi backend perangkat tersebut. Sesi backend juga kedaluwarsa setelah 30 hari tanpa aktivitas sesi. Untuk mencabut izin NotaKu secara keseluruhan, gunakan pengaturan akses aplikasi pihak ketiga pada akun Google Anda.

8. Perubahan kebijakan

Kebijakan ini dapat diperbarui ketika fitur NotaKu berubah. Versi terbaru akan dipublikasikan di halaman ini bersama tanggal pembaruannya.

9. Kontak

Untuk pertanyaan tentang kebijakan privasi atau penggunaan data, hubungi pemilik NotaKu melalui alamat kontak yang tercantum pada halaman aplikasi atau akun Google Cloud NotaKu.
